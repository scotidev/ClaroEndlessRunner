## 📖 Sobre o Projeto

**CONEXÃO FAVELA** é um jogo no estilo *endless runner 3D* desenvolvido na engine Unity. O jogo se passa em uma vibrante comunidade brasileira, onde a protagonista **Sol**, uma influenciadora local, corre para conectar pessoas e promover a sustentabilidade.

O objetivo é correr a maior distância possível, desviando de obstáculos *E-Lixo*(Celulares velhos, cabos emaranhados, baterias, modems antigo) e coletando "Globos de Conexão" para aumentar a pontuação. O jogo aborda a temática **ESG (Environmental, Social, and Governance)** de forma lúdica e acelerada.

Este projeto foi desenvolvido como Trabalho Final do curso **Desenvolvimento de Games - GAM3** da **SoulCode Academy**, com o tema proposto pela **Claro**.

### Principais Funcionalidades
* **Geração Procedural:** O caminho e os obstáculos são gerados infinitamente, garantindo que nenhuma corrida seja igual à outra.
* **Power-ups Temáticos:**
    * 🧲 **Booster da (Claro):** Aumenta a velocidade do personagem.
* **Ambientação Brasileira:** Cenários e identidade visual inspirados nas comunidades do Brasil.
* **Sistema de Score:** Pontuação baseada na distância percorrida e itens coletados.
